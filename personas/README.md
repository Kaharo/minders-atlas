# Персоны Пульса

Семь редакционных линз. Каждая новость получает теги персон по ключевым словам (`scripts/build-pulse.mjs`), затем персоны пишут разборы (`scripts/reflect.mjs`).

| Файл | Персона | Вопрос |
|---|---|---|
| `orbix.md` | ORBIX — Технологические системы | Что изменилось в самой технологии и надолго ли это? |
| `apex.md` | APEX — Власть и стратегия | Кто получает контроль и кто его теряет? |
| `meridian.md` | MERIDIAN — Экономические системы | Кто платит, кто зарабатывает и что это меняет в отраслях? |
| `lexicon.md` | LEXICON — Научный фронтир | Что действительно показано, а что пока гипотеза? |
| `archive.md` | ARCHIVE — Культура и общество | Как меняются привычки, работа, язык и культура? |
| `gaya.md` | GAYA — Планетарные системы | Во что это обходится планете? |
| `prism.md` | PRISM — Синтез знаний | Где сюжеты разных областей сходятся в один? |

- `_shared.md` — общие правила и формат ответа для всех персон.
- `_drafts.md` — инструкция для черновиков записей атласа.

## Где лежат разборы
- `atlas-pulse.json` → `personas.<id>` — дайджест дня (ru/en), его показывает карточка персоны в Пульсе.
- `atlas-pulse.json` → `items[].notes.<id>` — заметка персоны к конкретной новости.
- `pulse-archive/ГГГГ-ММ-ДД.json` — архив за каждый день.

## Как изменить персону
Отредактируйте её `.md`: вопрос, «На что смотрит», голос. Следующая ежедневная сборка уже пойдёт по новому профилю. Цвет и короткое описание на сайте задаются в `index.html` (массив `PERS`).
